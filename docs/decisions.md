- TensorFlow/Keras to PyTorch port (wp-002): the notebook's char-CNN is reimplemented in plain PyTorch with the same architecture (11,345,775 / 11,396,709 parameters), Adam 1e-3, batch 128, early stopping on val_accuracy (patience 4, best weights restored), under the optional `deep` extra (`uv add --optional deep torch`), imported lazily with an error naming `uv sync --extra deep`. Validation is the last 20% of a seeded shuffle of the training set, as Keras `validation_split` after the notebook's unseeded `np.random.shuffle`.
- Notebook bug fixed: the mixed-case run encoded its test set with the lowercase tokenizer; each variant now encodes train and test with its own alphabet.
- BiLSTM + GloVe port (wp-003): `lstm-glove` (5 classes) and `lstm-glove-3class` in plain PyTorch on the shared loop, with `gensim` added to the `deep` extra (`uv add --optional deep gensim`) only for loading `glove-wiki-gigaword-300` (`ModelConfig.embedding_source`, a downloader name or a local path). Same architecture and hyperparameters as the notebook (frozen embedding, BiLSTM 256 over 300 unmasked steps, dense 512/256/128, Adam 1e-3, batch 32, early stopping and ReduceLROnPlateau on val_loss with patience 1, validation = last 20% in dataset order).
- Keras to PyTorch LSTM details: Glorot-uniform input and dense weights, orthogonal recurrent weights, zero biases with forget-gate bias 1 (`bias_ih`; `bias_hh` stays 0). PyTorch keeps two bias vectors per direction, so the trainable count is 1,570,309 against Keras's 1,568,261 (+2048); the extra bias is accepted instead of emulating a single one. `reduce_lr_patience` follows Keras (reduce after N bad epochs, absolute `min_delta` 1e-4), mapped to torch's `patience - 1`.
- Notebook bug fixed: the LSTM was evaluated with the last epoch's weights although the best checkpoint was saved; the port restores the best `val_loss` weights (results are not comparable with the notebook's 0.6132).
- `TextPreprocessor` now follows the notebook's `remove_noise` order (lowercase, punctuation to spaces, contractions, `nltk.word_tokenize`, stopwords, join) and is used by the LSTM path. Because punctuation goes first, apostrophe contractions are not expanded ("that's" becomes "that s"); kept for parity.
- LSTM encoding parity: the vocabulary is built with `split()` but encoded like Keras `texts_to_sequences` (default filters turned into spaces, lowercased), so a kept token such as backslash+`nworst` is looked up as `nworst` and falls out of the vocabulary (index 0), as in the notebook.
- Polarity punctuation deletion uses the notebook regex `'[' + string.punctuation + ']'`, which leaves the backslash (a literal backslash-n is common in Yelp texts): vocabulary 22839 as in the notebook, against 22924 when every punctuation character is deleted (full-data polarity accuracy 0.8574 before, notebook 0.86034).
- Deep strategies take the class count from the experiment's label task (`ModelFactory` passes `n_classes`), not from `max(train_labels) + 1`; this also applies to the char-CNN.
